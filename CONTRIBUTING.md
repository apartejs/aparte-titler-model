# Contributing

Thanks for taking a look. This repository holds the runtime, the packages and the training pipeline of aparte-titler; the model weights and the benchmark live on Hugging Face.

## Ground rules

- **The JavaScript runtime must stay dependency-free and single-file.** Its only contract is the model file format (`format: 1`); the equality test against the Python reference implementation (`pnpm test`, 1,496 messages in five languages) must pass unchanged.
- **Never train on the benchmark.** The gold sets in [apartejs/aparte-titler-gold](https://huggingface.co/datasets/apartejs/aparte-titler-gold) are for evaluation only.
- **Numbers come from scripts.** Scores, tables and charts in the model card are generated by `python/eval/matrix.py` and `python/eval/charts.py`; do not edit them by hand.
- A new language, a new model or a new precision is a pull request that adds its files and re-runs the evaluation, not a hand-written table.

## Development

```bash
pnpm install
pnpm test                      # the runtime against the reference titles
python python/aparte_titler/reader.py packages/titler-latin/model/titler-v1-latin-int3.bin "your message"
```

The training pipeline (`python/pipeline/`) needs Python 3.11+, torch, tokenizers, numpy, pyarrow and datasketch, and a llama.cpp `llama-server` for the teacher model. See `python/pipeline/README.md`.

## Releases

Packages are versioned together with [Changesets](https://github.com/changesets/changesets). A change that keeps the model file format is a minor or patch release; a change of format is a major release, and the runtime keeps reading the previous formats.

## Reporting a problem

Open an issue on [GitHub](https://github.com/apartejs/aparte-titler-model/issues). For a poor title, include the message (or a similar one), the model file and the title you got.
